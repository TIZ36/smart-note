## Design Context

### Users
Solo knowledge worker (developer/PM) who ingests personal notes, meeting minutes, and project docs into a local AI knowledge base. Used daily at desk on macOS. The data layer supports sharing within a medium-sized team, but the UI is primarily a personal productivity tool — one person, one machine, deep focus.

### Brand Personality
**Calm, precise, understated.** Like a well-organized notebook — quiet confidence, nothing flashy. The interface should feel like a trusted instrument: reliable, fast, invisible when working, surfacing just enough structure to stay oriented.

### Aesthetic Direction
- **References**: Linear (information-dense, tight but elegant dark UI) + Notion (warm, spacious, content-focused)
- **Anti-references**: Discord (too gamified), Electron apps with generic shadcn defaults (too bland), anything with glowing neon accents
- **Theme**: Auto (follow macOS system appearance) — implement both light and dark. Dark is the primary design target since the user works at a desk, often at night.
- **Typography**: System fonts (SF Pro) are correct for a native macOS Tauri app. No web fonts needed.

### Design Principles
1. **Content over chrome** — Minimize UI furniture. The user's notes and search results are the interface; everything else is scaffolding that should recede.
2. **Earned density** — Tight spacing is fine when there's content to fill it (like Linear's issue list). But empty states and forms need generous breathing room.
3. **Quiet hierarchy** — Use weight, size, and opacity to create hierarchy. Avoid color-coding, badges, and decorative elements unless they carry meaning.
4. **System-native feel** — This is a macOS desktop app, not a web page. Respect platform conventions: traffic light spacing, native scrollbars, system font stack, subtle vibrancy.
5. **No AI slop** — No gradient text, no glow borders, no glassmorphism cards, no purple-to-blue accents. The current indigo accent (#6366f1) should be used sparingly and only for interactive elements.
