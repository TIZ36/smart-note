What changed from v2 — and why

  • Stream is the home, not a tab. RAG召回 + 历史 + agent行为 全部一条流，不再拆成 6 个 surface 切换 (your "5 柱不要").
  • Rail down from 6 to 4 icons. Notes / Wiki / Cloud / Settings 是低频跳转入口；Stream 没有 rail 按钮——点 logo 回家。
  • Asking is inline (B1). Enter 后 composed answer + chunks 在输入框正下方展开，下面 stream 被推下去——没有"提交-跳转-再返回"的硬切换。
  • Agent-reading is visible (E3). ambient bar 显示 "Now reading: Claude Code" + 顶 banner + 那条 stream 行高亮——三处一致地表达"agent 正在用你的记忆"。
  • Each row is actionable. Open / Re-enrich / Accept / Reject inline；hover 才显 Copy-as-MCP（不抢戏）.
  • Library = Docs · Memories · Skills (3 sub-tabs). rail 标签从 Wiki 升级成 Library — 三种知识资产同源（agent/你 长期积累、被 MCP 调用），共用左树+右内容 chrome：
    　· Docs — 你 ingest 的长文，左树按 AI topic 归类（C2 · 可切 Files）；右上 View raw ↗ 直达原始 markdown 源（topic 是知识化的，原文随时可回查）
    　· Memories — 双入口：(a) AI CLI 通过 MCP propose_memory 上传的对话经验；(b) 每天定时把当天 Stream 整合成候选 memory（synthesize from N events，confidence 通常更高因为多源验证）。左树有独立 "Daily digests" 分组按日维护，pending 列表区分两种来源
    　· Skills — 给 AI CLIs 用的 SmartNote skill 文件 + 自定义 workflow（claude-skill / dap-callback-developer / …），按 agent 分组，含调用次数
  • Rail badge 从总数 → pending count (5). badge 只在"需要你看"时出现（earn every accent）— 总数无行动力，pending（含 AI CLI propose + 每日 digest 候选）才有。
  • Cloud modal 加第 4 个 action: Run today's digest. 默认每天定时跑，但用户可手动早一点触发——本质是个 algorithm trigger，跟 Trigger enrich / Run AI tag pass 同类。
  • Cloud = lightweight center modal (D3). 不是独立 page、不是 4 tab console——只放：库存 / 设备 + plan / 3 个一键动作 / auto-enrich 开关 / MCP endpoint。

  • No drop shadow, no glassmorphism, no gradient text, no left-stripe accent.
  • Single blue accent appears only when an agent reads (banner + ambient pulse) or you must act (Accept / inline answer dot).
  • Information is dense via 4-multiple spacing, not via cramming.
